# Отчёт: Обратное проектирование алгоритма

## 1. Анализ алгоритма

**Входные данные:**  
Целое число `n` (верхняя граница диапазона)

**Выполняемые действия:**  
Программа перебирает числа от 1 до `n`, проверяет условие, суммирует подходящие числа и считает их количество, затем вычисляет среднее арифметическое.

**Условие отбора значений:**  
`i % 3 == 0 and i % 2 != 0` (число кратно 3 И число нечётное)

**Итоговый результат работы программы:**  
Сумма и среднее арифметическое нечётных чисел, кратных 3, в диапазоне от 1 до `n`.

---

## 2. Назначение переменных

| Переменная | Назначение |
|------------|------------|
| `n` | Верхняя граница диапазона (ввод пользователя) |
| `result` | Сумма отобранных чисел |
| `count` | Количество отобранных чисел |
| `average` | Среднее арифметическое = result / count |

## 5. Изменение алгоритма

**Задача:** изменить программу для обработки чётных чисел, кратных 4.

**Новое условие:** `i % 4 == 0`

**Изменённый код:**

```python
n = int(input("Введите число: "))
result = 0
count = 0

for i in range(1, n + 1):
    if i % 4 == 0:
        result += i
        count += 1

if count > 0:
    average = result / count
    print("Результат: ", result)
    print("Среднее значение:", average)
else:
    print("Подходящие числа отсутствуют")
Пример работы при n = 20:
Числа: 4, 8, 12, 16, 20 → Сумма = 60, Среднее = 12.0
