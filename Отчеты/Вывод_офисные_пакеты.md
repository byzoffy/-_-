# Вывод по офисным пакетам

Наиболее удобный для учёбы: Google Workspace

Почему:
- Бесплатно
- Доступ с любого компьютера (через браузер)
- Совместная работа в реальном времени (удобно для групповых проектов)
- Автосохранение в облаке — работа не потеряется

Минусы других:
- Microsoft 365 — платный
- LibreOffice — нет совместной работы и проблемы с форматированием
